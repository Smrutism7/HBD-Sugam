PROJECT SUGAM — SONG FINALE

Files: index.html, style.css, script.js, qr-cards.html.

SETUP
1. Open script.js and replace PASTE_UPDATED_SONG_LINK_HERE with the shareable URL of your corrected custom song.
2. Upload all four files to the root of the existing GitHub Pages repository.
3. Open https://YOUR-SITE/qr-cards.html, paste your published site base URL and generate QR cards.
4. Print one welcome QR for the birthday card plus seven hidden QR codes.

HUNT ORDER
Welcome card: main site (no stage parameter); opening mirror riddle.
Stage 1: bathroom mirror -> bookshelf.
Stage 2: bookshelf -> office closet.
Stage 3: office closet -> refrigerator. First wrapped gift + confetti.
Stage 4: refrigerator -> wardrobe.
Stage 5: wardrobe -> sofa. Second wrapped gift + confetti.
Stage 6: sofa -> his car.
Stage 7: inside his car. Final wrapped RC car + confetti; romantic letter; optional final song reveal button.

No dining-table or bedside-drawer QR is needed.
Old printed stage 1-7 QR codes have the same destinations, but stage 8 is retired. Print new cards if you want the updated text on the cards.

TEST
Test the opening, every stage URL, gift celebrations, final letter, and song URL on a phone. Make sure the song is publicly accessible to anyone with the link. Avoid exposing sensitive information in this public static website.
